How this engine works

Method & conventions

Every line is units × content × price from the physical layer up — accelerator units from the house AI Model (hard to CY28), memory bits from UBS (05-12), network units/ASPs from the house Susquehanna-based deck, GW from units × kW × PUE. Top-down paths never feed the engine; they only grade it.
Anti-double-count conventions: HBM + LPDDR travel inside accelerator ASPs (kept as memo lines); the memory line sums only what hyperscalers buy directly (server DDR5 + DC NAND + nearline HDD); NVDA revenue base is Compute ex-networking (swapping to DC-total would inject ~$125bn of double-count in CY27); Grace/Vera CPUs live inside NVDA Compute, so the CPU line counts merchant x86 only.
Audit trail: 4 hostile skeptic passes (2026-07-16 → 07-24), PARTIAL→PASS after fixes; 204 source comments in the workbook, every datapoint carrying broker/analyst + date.
